# European IT LMS

- `frontend/` — Next.js application source, public assets and build configuration.
- `backend/` — Express API, Prisma schema/migrations and operational scripts.
- `resources/` — frontend checks, backend tests, Postman collections, supporting documentation and design references.
- `record.md` — dated implementation history, validation evidence and outstanding work.

Start with the [frontend setup](frontend/README.md), [backend setup](backend/README.md), [resource index](resources/README.md) or [work record](record.md).

The frontend API map and milestone plan are local references under `resources/frontend/docs/` and `resources/frontend/plans/`; both remain gitignored. Runtime dependencies and generated build outputs stay in their tool-managed locations and are ignored.
